## What I've Been Building

**RAG Chatbot for University Website** — `Python` `LangChain` `LLM APIs`
A Retrieval-Augmented Generation chatbot answering student queries by grounding an LLM's responses in content scraped from the university website. Document chunking, embedding, and semantic retrieval orchestrated with LangChain.

**Multi-Agent Job/Internship Application System** — `Python` `LangChain` `Automation`
A multi-agent pipeline that scrapes postings, matches them against a candidate profile, submits applications, and tracks status end-to-end. Distinct agent roles for scraping, matching, applying, and tracking.

**English-to-Urdu Neural Machine Translation** — `Python` `PyTorch`
A sequence-to-sequence translation model built on an LSTM encoder-decoder, then re-implemented with a from-scratch Transformer to compare results against the LSTM baseline.

**Real-Time Theft Detection System** — `Python` `PyTorch` `YOLO` `OpenCV`
Real-time object detection flagging theft-related activity from live video. A scaled-down personal implementation inspired by large-scale public safety surveillance systems.

**Urdu OCR** — `Python` `PyTorch` · *in progress*
An OCR system for Urdu script, working through the challenges of cursive and connected character recognition.

Also built: a Transformer implemented from scratch after reading the foundational papers, image captioning (CNN + LSTM + attention), handwritten digit and character recognition, a synthetic data enhancement platform, a stock movement predictor, a spam classifier, and full-stack web projects.
